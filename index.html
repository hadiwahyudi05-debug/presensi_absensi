Proteksi Keamanan Data & Antivirus

Konfigurasi ini memastikan data sekolah aman saat dihosting di GitHub dan disimpan di ekosistem Google.

Google Workspace
Terlindungi
  • Enkripsi Payload: Data yang dikirim dari HTML ini ke App Script dienkripsi (Base64/AES) mencegah penyadapan.
  • Google Drive Antivirus: Aktifkan Advanced Protection pada akun Google Admin untuk otomatis memindai file lampiran presensi dari malware.
  • Restriksi Akses Sheet: Pastikan Google Sheet data TIDAK dibagikan "Anyone with link". Hanya service account/Apps Script yang memiliki akses baca/tulis.
Hosting GitHub Pages
Secure Host
  • Proteksi CORS Domain: Konfigurasi App Script untuk hanya menerima permintaan (Request) dari URL spesifik.
  • API Token Header: Pengiriman data presensi wajib menyertakan Bearer Token terenkripsi pada Header request.
  • Anti-XSS & Sanitization: Semua input form pada frontend telah disanitasi otomatis oleh sistem.
